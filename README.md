# 서울 건폐율·용적률과 정북일조 검토기

대지면적과 층별 바닥면적, 층고를 넣으면 서울특별시 조례 기준으로 **건폐율·용적률**과 **정북일조 사선제한**을 한 번에 검토해 주는 앱입니다. 값을 바꾸면 판정 결과와 정북 방향 단면도가 바로 다시 그려집니다.

파이썬 기초 수업의 과제("함수, 조건문, 반복문을 활용한 앱을 만들어 GitHub에 올리고 Cloudflare로 발행")로 만들었습니다.

- 배포 주소: (solar-break.pages.dev)

## 무엇을 검토하나

| 항목 | 내용 |
|---|---|
| 건폐율 | 건축면적 ÷ 대지면적. 용도지역별 한도와 비교해 적합/초과 판정 |
| 용적률 | 지상층 연면적 ÷ 대지면적. 한도와 비교하고, 남은 면적으로 몇 층을 더 올릴 수 있는지 계산 |
| 정북일조 | 층마다 상단 높이를 구해, 정북 방향 인접 대지경계선에서 띄워야 하는 거리와 비교. 사선제한선을 넘은 부분을 단면도에 빨간색으로 표시 |

숫자가 아닌 값이나 0 이하의 값을 넣으면 해당 칸 아래에 다시 입력하라는 안내가 나옵니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 웹 앱. HTML·CSS·JavaScript가 한 파일에 들어 있어 이 파일만으로 동작 |
| `seoul_building_check.py` | 같은 계산을 하는 파이썬 버전. 로직을 먼저 파이썬으로 짜고 검증한 뒤 JavaScript로 옮김 |
| `README.md` | 이 문서 |

## 실행 방법

**웹 앱**: `index.html`을 브라우저에서 열면 됩니다. 설치할 것은 없습니다.

**파이썬 버전**:

```bash
python seoul_building_check.py
```

질문마다 Enter만 누르면 `[ ]` 안의 예시 값(대지 330㎡, 제2종일반주거지역, 4층)이 들어갑니다. 주피터 노트북 셀에 코드를 붙여넣어 실행해도 됩니다.

## 함수, 조건문, 반복문이 쓰인 곳

수업 노트북의 소수 판별기와 같은 뼈대를 따랐습니다.

```
입력 받기(검증) → 반복문으로 계산 → 조건문으로 판정 → 결과 출력
```

파이썬 파일에는 `[함수]` `[조건문]` `[반복문]` 주석을 달아 두었고, `index.html`의 각 JavaScript 함수 위에는 대응하는 파이썬 코드를 주석으로 적어 두었습니다.

| 요소 | 파이썬 (`seoul_building_check.py`) | JavaScript (`index.html`) | 하는 일 |
|---|---|---|---|
| 함수 | `ask_number()` | `parseNumber()` | 입력값 검증. 숫자가 아니면 다시 입력하도록 안내 |
| 함수 | `main()` | `main()` | 입력 → 계산 → 판정 → 출력 함수를 순서대로 호출 |
| 조건문 `if / else` | `judge()` | `judge()` | 한도 이하면 적합, 넘으면 초과 |
| 조건문 `if / else` | `required_setback()` | `requiredSetback()` | 높이 10m 이하면 1.5m, 넘으면 높이의 1/2 |
| 조건문 `if / elif / else` | `decide_limits()` | `main()` 안의 한도 결정 부분 | 직접 입력 / 소규모 건축물 완화 / 서울도심에 따라 한도 분기 |
| 반복문 `for` | `sum_floor_area()` | `sumFloorArea()` | 층별 바닥면적을 더해 연면적 계산 |
| 반복문 `for` | `largest_floor_area()` | `largestFloorArea()` | 가장 넓은 층 찾기 (건축면적 어림) |
| 반복문 `for` | `check_solar()` | `checkSolar()` | 층마다 높이를 누적하며 필요한 이격거리와 비교 |
| 반복문 `while` | `count_extra_floors()` | `countExtraFloors()` | 남은 연면적으로 더 올릴 수 있는 층수 세기 |
| 반복문 `while` | `ask_number()` | (웹은 칸 아래 안내문으로 대체) | 올바른 값이 들어올 때까지 다시 묻기 |
| 이중 `for` | `draw_section()` | `drawSection()` (SVG) | 층 × 가로 칸을 돌며 단면도 그리기 |
| dictionary / list | `ZONES` | `ZONES` | 용도지역별 건폐율·용적률 한도 |

## 계산 기준

**건폐율·용적률**: 「서울특별시 도시계획 조례」(조례 제10139호, 2026. 7. 13. 시행) 제44조, 제48조

| 용도지역 | 건폐율 | 용적률 |
|---|---|---|
| 제1종전용주거지역 | 50% | 100% |
| 제2종전용주거지역 | 40% | 120% |
| 제1종일반주거지역 | 60% | 150% |
| 제2종일반주거지역 | 60% | 200% (완화 시 250%) |
| 제3종일반주거지역 | 50% | 250% (완화 시 300%) |
| 준주거지역 | 60% | 400% |
| 중심상업지역 | 60% | 1,000% (서울도심 800%) |
| 일반상업지역 | 60% | 800% (서울도심 600%) |
| 근린상업지역·유통상업지역 | 60% | 600% (서울도심 500%) |
| 전용공업지역·일반공업지역 | 60% | 200% |
| 준공업지역 | 60% | 400% |
| 보전·생산·자연녹지지역 | 20% | 50% |

- "완화 시" 값은 같은 조례 제51조제2항제9호에 따라 시행령 상한까지 적용한 것입니다. 대상 여부는 서울시장이 따로 정한 운영기준으로 판단하므로, 앱에서는 선택 항목으로 두고 기본값은 꺼 두었습니다.

**정북일조**: 「건축법 시행령」 제86조제1항, 「서울특별시 건축 조례」 제35조제1항

- 높이 10m 이하인 부분: 정북 방향 인접 대지경계선에서 1.5m 이상
- 높이 10m를 넘는 부분: 해당 부분 높이의 1/2 이상
- 전용주거지역과 일반주거지역에만 적용

## 한계

학습용 도구이며, 실제 인허가 검토를 대신하지 않습니다.

- 건축면적은 가장 넓은 층의 바닥면적으로 어림합니다.
- 연면적은 지상층만 더합니다. 지하층, 주차장 등 용적률 산정에서 빠지는 면적은 다루지 않습니다.
- 임대주택·공공시설 제공에 따른 용적률 완화, 학교이적지, 정비사업, 지구단위계획구역, 용도지구(경관지구 등)의 제한은 반영하지 않습니다. 필요하면 "한도 직접 입력"을 사용하세요.
- 정북일조는 정북 방향 한 면의 단면만 검토합니다. 도로·공원에 접한 대지의 완화, 대지 간 고저차, 정북 방향이 대지경계선과 비스듬한 경우는 다루지 않습니다.
